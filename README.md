# Document Q&A System — RAG Pipeline with LangChain + FAISS
Document Question Answering system using Retrieval-Augmented Generation (RAG).

## Features
- PDF / DOCX support
- FAISS vector database
- Sentence Transformer embeddings
- Gemini-powered answer generation
- Gradio interface

## Tech Stack
Python, LangChain, FAISS, Gemini API, Gradio

## Workflow
Document Upload
↓
Chunking
↓
Embeddings
↓
FAISS Retrieval
↓
Gemini Answer Generation
